# 🖼️➡️🔊 Image to Audio Description using Generative AI

## 📌 Project Overview
This project implements an **image-to-audio description system** using **Generative AI**, designed to convert visual inputs into meaningful spoken descriptions. The application accepts an image, generates a descriptive caption using an AI model, and converts the text output into audio, enabling multimodal interaction and accessibility-focused use cases.

## 🎯 Objective
The primary objective of this project is to understand and implement a **basic AI-driven processing pipeline** that integrates computer vision, natural language generation, and text-to-speech synthesis within a single application.

## 🧠 System Pipeline
- User uploads an image through a **Streamlit web interface**
- The image is preprocessed using **Python** for model compatibility
- A **Generative AI image captioning model** analyzes visual features
- The model generates a descriptive text caption
- The generated text is passed to a **Text-to-Speech (TTS) engine**
- The TTS module converts text into an audio output
- The audio file is rendered and played back in real time via the UI

## 🛠️ Technologies Used
- **Python** – Core application logic  
- **Streamlit** – Web-based user interface  
- **Generative AI Model** – Image caption generation  
- **Text-to-Speech (TTS)** – Audio synthesis  
- **Visual Studio** – Development, debugging, and workflow management  

## 🚀 Key Learnings
- End-to-end AI application pipeline design  
- Integration of vision, language, and audio modules  
- UI development using Streamlit  
- Handling user input, real-time output, and application flow  
- Practical exposure to AI-based software development
